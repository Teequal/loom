# Review: 25 Oct feedback

Jacob's feedback after using the table page, Develop, wrap-up and the campaign page. Backup taken first: git tag `backup-2026-10-25-before-review` and `data/backups/loom-2026-10-25-before-review.db`.

## What the feedback says, and what's behind it

**1. Develop is a dead end.**
- Develop produces an intro, setups and directions, but none of them can be used or developed further.
- Nothing from Develop is logged or kept: reload the page and it's gone.
- What's needed is a branching tree. Pick a development, it joins the session, develop from it again, and so on, until you stop and wrap up.
- In the code, a log entry has no parent, so there's no way to represent a branch.

**2. Questions are easy to miss.**
- Pending yes/no questions appear in two places: under the current cards (below the fold once there are three options), or inside a timeline entry you have to open.
- Nothing says they must be resolved. The database already shows one unanswered question in Duradan's session 6.
- They should sit in view near the last thing you did, look clearly unfinished, and stay there until answered.
- An auto-approve option suits DMs who trust it.

**3. The text box scrolls away.**
- After asking, the options push the box up the page. Using an option or developing it means scrolling back up to type the next moment.
- The box should always be within reach.

**4. Nothing is clickable: "the LOOM idea".**
- Thread chips, names in option text, thread summaries, people in a relationship and moments are all inert.
- The data to traverse it all already exists:
  - entity → relationships → other entities;
  - entity → threads → involved entities and linked threads;
  - thread → history by session;
  - entity → change history (`historyOf`), moments and sessions.
- None of it is reachable by clicking.
- The page has rows that open in place, but no way to go from one row to another.

**5. The campaign page is bare.**
- It's a set of lists. There's no overview of the party (status and conditions), of what's hot or quiet, or of how things connect.

## Design decisions

**The Loom inspector** is one traversal layer used on every page.
- Anything with an identity (a thread, a character, a place, an item, a faction, a key moment, a session) renders as a link.
- Hovering (or a long press on touch) shows a small preview card: what it is, its status and one line.
- Clicking opens the inspector, a side panel on desktop and a bottom sheet on a phone. It shows the thing's full detail, and every connection in it is itself a link.
- A breadcrumb trail records the path (Khayiulad › Figurine use is driving… › Salaena › …), so you can go back a step or jump back to any earlier point.
- At the table it opens beside the page, so the box and options stay put.
- Names inside text (option text, summaries, descriptions, notes) link automatically, using the names and aliases of everything in the campaign.
- **Which interaction where:**
  - **Hover** for a quick look.
  - **Click** to go deeper.
  - **Expander** for long lists inside a node (full history, every relationship). This keeps the first view short.

**The campaign page** opens on an overview built from links:
- the party, each with status, health and conditions;
- threads in play now (touched most recently) and quiet threads;
- the cast grouped by importance;
- recent sessions and key moments.

The search and tabs stay underneath as the index. Every row opens the inspector.

**Branching:**
- Each item Develop produces (the intro, each setup, each direction) gets **Use this** and **Develop further**.
- Using one logs it as a child of the choice it came from (`live_entries.parent_id`) and extracts it like any other choice. Developing further develops from that item.
- Develop results are kept on the entry, so the tree survives a reload.
- On the timeline, a child appears next to its parent with a connector. Opening an entry shows its branch: parent, children and siblings.
- Wrap-up drafts the notes as an indented tree.

**Questions:**
- A **"needs your answer" tray** is pinned just above the box, so it's visible wherever you are.
- It shows each pending question with its reason and the quote it's based on. The colour signals it's unfinished, and it disappears only when the question is answered.
- **Auto-approve** is a per-campaign switch: risky changes are applied as your own entries without asking. They're still marked in the timeline and can be undone with Take back.

**The text box:**
- The box sticks to the top while you scroll the options.
- It grows as you type.
- "/" focuses it from anywhere.
- After you use an option, focus returns to it with "What happened next?".

## Not changing

- **The table page's layout:** options stay below the box, with the timeline above. That works and is familiar.
- **Extraction stays in the background** on Sonnet.
